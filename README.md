# Portfólio profissional

Site estático em português e inglês. Abra `index.html` no navegador para visualizá-lo; não há instalação nem servidor obrigatórios. O botão de impressão também permite salvar o perfil em PDF pelo navegador.

## GitHub Pages

Este repositório publica o site pelo GitHub Pages a partir da branch `main` e da pasta raiz. Após a ativação, o endereço será:

https://heglas.github.io/portfolio-profissional/

O site funciona com caminhos relativos, inclusive em subpastas do GitHub Pages, e usa fontes locais.
